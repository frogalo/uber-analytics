# 🚗 Uber Data Analyzer 🍽️

**Uber Data Analyzer** is a sleek and powerful web application designed to give you deep insights into your **Uber Rides** and **Uber Eats** history. With beautiful charts, interactive tables, and detailed statistics, it helps you truly understand your spending habits and ride/order patterns.

---

## ✨ Features

* 📊 **Monthly Spending Charts**
  Visualize your monthly expenses on both Uber Rides and Uber Eats.

* 💃 **Interactive Tables**
  Sort, filter, and explore your trips and orders with ease.

* 💸 **Comprehensive Stats**
  Total spending, number of rides/orders, and item counts at a glance.

* 🔍 **Detailed Breakdowns**
  Dive into each ride or order — see locations, items, costs, and more.

* 📅 **Simple Upload**
  Drag and drop your Uber export data and instantly get insights.

---

## 🚀 How to Use

### 1. Request Your Uber Data

To get started, you'll need to download your Uber data.
👉 [Request your Uber data download](https://auth.uber.com/v2/?breeze_local_zone=dca20&next_url=https%3A%2F%2Fmyprivacy.uber.com%2Fprivacy%2Fexploreyourdata%2Fdownload%3Fautoauth%3Dfalse%26show_header%3Dtrue&state=p_yI5HxUzM2XCi37rtCZIvBSvbVbMJnjGi2vuRybTEg%3D)

Uber will send you an email with a link to download a ZIP file containing your data.

---

### 2. Extract the Data

Once you've downloaded the ZIP file:

* Extract it to a folder.
* Inside, you'll find CSV files like `trips_data.csv` and `user_orders.csv`.

---

### 3. Upload to the App

* Open the **Uber Data Analyzer** web application.
* Use the **Upload** button to select and upload your CSV files.
* Sit back as the app processes your data and brings your Uber history to life with beautiful analytics.

## 💪 Development

### Prerequisites

* [Node.js](https://nodejs.org/) (v18+ recommended)
* [npm](https://www.npmjs.com/)

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/uber-data-analyzer.git
cd uber-data-analyzer
npm install
```

Start the development server:

```bash
npm run dev
```
